# Akki Image Converter 0.1.6

Stable release for Windows 11 x64.

- Removes the Preview badge from the app.
- Displays third-party licences and notices inside the app, with a document selector and scrolling text viewer.
- Removes usage statistics, analytics requests, the statistics setting, and installation identifiers from the app.
- Preserves appearance, conversion and update preferences when loading older settings; retired statistics fields are discarded when settings are saved.
- Includes Light, Dark and Windows appearance options, batch conversion, resizing, preview comparison and installed-app updates.

The installer and portable build remain unsigned. The installer includes the required runtimes and creates Desktop and Start-menu shortcuts.
