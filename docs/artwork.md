# App artwork

Generated with the built-in image generation tool on 2026-10-26.
The generated master is preserved in `src/Akki.ImageConverter/Assets/ArtworkMaster.png`.
`scripts/ExportArtwork.ps1` exports a transparent 256px `AppLogo.png` and a Windows
`App.ico` containing 16, 20, 24, 32, 40, 48, 64, 128 and 256px images.

## Generation prompt

Use case: logo-brand. Create a production-ready Windows 11 app icon for Akki Image Converter, an image format batch converter. One single centered icon, no text or letters. A polished Fluent-style rounded square tile in rich cobalt blue with subtle cyan illumination and restrained depth. Inside, a bold white stylized landscape/photo symbol with two simple mountain peaks and a small sun, combined with a single elegant cyan conversion arrow wrapping the lower right edge. Strong simple silhouette, readable at 24px, professional utility software identity, carefully balanced generous internal padding. Front view, no perspective, no surrounding scene, no separate cast shadow outside the tile. Genuine transparent background outside the rounded tile. Square canvas, icon fills about 88 percent of width. No watermarks, no mockup labels, no multiple variants.
